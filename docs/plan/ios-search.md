# Native transfer search and filters

Roadmap 09 combines native search with status, category and provider-account navigation pickers. Search matches every word across bounded names, hashes, category and account labels, folding case, diacritics and width. It preserves server ordering and caches folded strings between query edits. Active, needs attention and completed scopes share the transfer stage model; unknown stages need attention. Empty and missing categories share Uncategorized; a category literally named Uncategorized remains separately selectable.

Account labels come from the authenticated accounts listing, refreshed on foreground/reconnect/account invalidation. An unavailable account retains an honest fallback; metadata failure preserves the transfer snapshot. Search and filters apply together, report matching counts and expose a single clear action. A true empty server and no matching results have different states. Controls use native search, forms, navigation pickers and sheets; no custom gesture or animation replaces stock behavior.

Queries may contain private filenames. One actor saves a versioned envelope bound to the exact canonical server URL in Application Support with complete file protection, atomic writes, an 8 KB limit and at most 16 owned profile files. No plaintext fallback, defaults storage or extension credential sharing. Saves debounce 400 ms; leaving flushes state. A delayed restore checks the input revision before applying, and never replaces typing. Failed persistence is visible without revealing stored content. Simulator file-protection metadata is optional; device checks require complete protection and lock/unlock verification remains a physical-device gate.

Validation: 82 core Swift Testing functions and nine UI tests pass on the one shared iOS 27.0 simulator. Search coverage includes combined criteria, Unicode, unknown states, category ambiguity, a 2,000-transfer fixture, delayed restore, protected storage roundtrip, corruption/size limits and retention. UI flows exercise no-match search and native status selection/reset. Debug-only previews use fictional transfers and account labels, with no network, session store or persisted search. Light/dark simulator captures and unsigned arm64 compilation supplement independent source review; VoiceOver device behavior and physical protection remain milestone 28/29 checks.
