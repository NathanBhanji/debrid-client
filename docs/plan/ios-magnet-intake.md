# Native magnet intake domain

Roadmap 12 introduces a validated, extension-safe MagnetLink value without adding routing, submission or network access. The later inbox, URL delivery, paste/import and review milestones consume it. Parser success must never submit automatically.

Submission uses rawURI: the original UTF-8 String with only surrounding Go-compatible Unicode whitespace removed. Parameter order, encoding/case, repeated trackers, plus signs, unknown parameters and hybrid topics stay untouched. No URL/URLComponents reconstruction or tracker fetching occurs. infoHash is separately normalized for identity; equivalent hashes do not erase differences between submitted links. Display name is the first dn (including an empty first dn), decoded for display, capped at 256 Unicode scalars and stripped of format controls. Presentation metadata must never reconstruct the submitted link.

The current backend torrentmeta.ParseMagnet delegates to anacrolix ParseMagnetV2Uri and requires a v1 hash. Swift supports 40-character hex and 32-character uppercase base32 btih, plus hybrid links with canonical SHA2-256 btmh (1220 followed by 64 hex characters). It rejects v2-only links, same-type duplicate topics, malformed hashes and invalid hybrid topics. Unknown topic namespaces remain in the raw URI. This policy follows the current backend and the [BEP 9 magnet format](https://www.bittorrent.org/beps/bep_0009.html); it does not claim general v2-only provider support.

Native intake deliberately accepts a safe subset of Go parsing: malformed escapes/UTF-8 in any field, raw spaces, fragments, unescaped semicolons and decoded control characters fail instead of relying on Go query parsing to discard or reinterpret a field. Literal plus uses form-query semantics for metadata only; the raw link remains unchanged. Encoded spaces, semicolons and hash marks remain valid parameter content. Noncanonical multihash encodings are outside the native policy. Errors are static and contain no input text.

The full input is bounded to 65,536 UTF-8 bytes before trimming, and at most 512 query fields. No credentials or tracker arrays are exposed as presentation metadata: only a tracker count is needed. Descriptions, debug strings and reflection redact the entire link. The rawURI property is explicit private user content; callers must keep it out of logs/defaults and persist it only in the protected inbox introduced by roadmap 13.

A 24-case credential-free corpus is generated from the actual backend parser by tools/iosmagnetfixtures, integrated into make generate/generate-check and bundled for Swift tests. The generator refuses to claim a native-accepted example that the server rejects. Swift checks both acceptance and decoded hashes/names; stricter-native cases are explicit. Additional tests cover exact URI roundtrip, hash equivalence without option loss, duplicates/hybrid policy, bad percent/UTF-8/control input, byte/parameter boundaries, bounded metadata and redacted descriptions/reflection/errors. All 108 core tests passed on the reused iOS 27.0 simulator. UI is unchanged, so no new screenshots or UI-suite repetition is needed for this domain-only increment.

Validation also passed make generate-check, focused Go torrentmeta/generator compilation tests and unsigned arm64 iPhone compilation/linking. Independent source/documentation review approved. No production input, provider fetch or mutation was performed.
