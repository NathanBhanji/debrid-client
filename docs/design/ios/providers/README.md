# Providers · native SwiftUI captures

Actual iOS 27.0 shared-simulator screenshots from the production provider list/detail/settings views, driven by the in-memory `ProviderFixtureAPI`. All accounts and checks are fictional; no production credentials, providers or transfers were contacted. Native tab/navigation materials come from SwiftUI. These are PNG captures, not HTML reconstructions.

- providers-dark / providers-light: enabled, default and disabled saved accounts.
- provider-unchecked / provider-checked-dark: deliberate credential checking and dated membership/expiry.
- providers-empty / providers-offline: empty server versus unavailable response.
- connection-settings: server address, Pocket ID identity and app version.
- provider-error-largest: final failed-check state at Accessibility XXXL.
- providers-search-empty: search with no matching accounts.

See [behavior, review and tests](../../../plan/ios-provider-overview.md). Final acceptance still includes a physical iPhone, full VoiceOver navigation and signed App Group/Keychain checks.
