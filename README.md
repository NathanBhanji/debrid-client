# debrid-client

Go-based debrid download manager: HTTP API, CLI, MCP server. Web UI later.

Status: early development. See [docs/DESIGN.md](docs/DESIGN.md), [docs/PR-PLAN.md](docs/PR-PLAN.md) and [docs/research/](docs/research/).

## Development

```sh
make build   # → bin/debrid
make test
make lint    # golangci-lint via go run
```
